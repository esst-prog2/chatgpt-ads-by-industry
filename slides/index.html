04 · What I learned

Google sign-in needs an address that never changes

  1. 2 NovGoogle refused my LAN addressA raw IP can't be an authorized redirect URI: it "must end with a public top-level domain".
  2. TunnelPublic, but randomA localtunnel gave a real HTTPS hostname, yet a new one on every restart, so the URI had to be re-registered each time.
  3. The hidden bugRight host, wrong schemeThe tunnel forwards raw TCP with no X-Forwarded-Proto, so the app built http:// and Google saw a mismatch. Fix: FORCE_HTTPS_URLS, checked with a spoofed Host header and a test.
  4. 14 NovOne fixed subdomain--subdomain <name> gives the same https://<name>.loca.lt every run: one URI, registered once.

The rule nowOAuth only trusts a pre-registered, exact redirect URI. Make the address deterministic first, then make the app print it exactly: scheme, host and path.
